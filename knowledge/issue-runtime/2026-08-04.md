### CASE: depends-on-line-must-not-be-bulleted
status: distilled
problem: Appended `Depends-On: 23` / `Depends-On: 24` lines for issues 24/25 were written with a leading "- " bullet to match the file's visual house style.
decision: Strip the leading "- " so the lines read exactly `Depends-On: 23` and `Depends-On: 24`.
why: The parser's `_DEPENDS` regex requires an exact `Depends-On:` prefix; the bulleted form falls through as ordinary body text and `parse()` returns successfully without raising, silently dropping the dependency chain instead of erroring.
tags: [parser, issues-md, dependency-chain, silent-failure]

#### JUDGMENT (distilled 2026-08-09)
Rejected alternative: writing the `Depends-On:` lines with a leading "- " bullet to match the file's visual house style.
Tradeoff: bulleting matches the file's visual style, but the parser's regex requires an exact prefix — the bulleted form falls through as body text and `parse()` returns successfully without raising, silently dropping the dependency chain; stripping the bullet costs visual inconsistency with the rest of the file but preserves the actual dependency chain.
Tipping factor: the parser's exact-prefix regex silently drops the dependency chain instead of erroring on a bulleted line, caught only by an explicit inline parse-check, not by the parser itself.
